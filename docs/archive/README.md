# Archive

These are the earlier plans for COAL. They are **history, not the current plan**. The current plan starts at [docs/README.md](../README.md).

| File | What it is |
|---|---|
| [01-base-layer-plan.md](./01-base-layer-plan.md) | Sharath's base-layer plan (16 Nov 2026): workflow engine, dashboard widgets, permissions, data model and APIs |
| [02-ai-layer-plan.md](./02-ai-layer-plan.md) | Sharath's AI-layer plan (16 Nov 2026): the Workstation, the AI's identity and permissions, tools, skills and flows |
| [PLAN.md](./PLAN.md) | Madhav's plan, draft 2 (16 Nov 2026): Indian regulation, signatures, clearance, SolidWorks, shop floor, hosting, costs, team and risks |
| [plan-comparison.md](./plan-comparison.md) | The comparison of the two plans (17 Nov 2026) that the current plan was built from |

**When to use them**

- They are useful background when the current docs leave something out. Madhav's `PLAN.md` holds the most detail on regulation, the SolidWorks connector, the shop floor, hosting costs and risks.
- Anything taken from here into the current plan must be re-checked first. Some of it was decided differently, or depends on information we don't have yet.
- Don't edit these files, except to fix broken links.

**Known gap:** `PLAN.md` links to research reports in `docs/research/`, which were never added to the repo.
